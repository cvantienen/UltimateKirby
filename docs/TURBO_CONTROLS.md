# Shortcuts and button recipes

**Minus** opens/closes the menu. Outside Training, R3 switches between the
lightweight ledge selector and Buttons / Assists. Training retains editing tools.

With the menu closed, **hold L3 without L** for the existing turbo teabag/creep
helper if enabled by `r3_turbo`/`l3_turbo`. Release to stop. Native readiness,
airborne state, stop clocks and action ownership can suppress it. L3 in a
Training assist list is a menu control instead: it opens/returns from that list.

X, Y and all four D-pad directions have fighter-specific input recipes. Choose
**Normal button** to restore X's grounded short-hop shortcut, ordinary Y or
ordinary D-pad input. X must be mapped to Jump. Recipes can run once per press
or loop while held; tap/hold actions are configured in their recipe editor.

The old Y native Finisher selector, A+B jab-to-grab and hard-coded D-pad
slide/B-reverse/trump bindings are removed. Assist modes use their ON/OFF menu
rows. Existing reaction-rule toggle groups are separate metadata and remain
compatible; they are not generic button-to-mode bindings.

See [controls](CONTROLS.md), [input recipes](SEQUENCE_FILES.md),
[assist rules](REACTION_RULES.md) and [posture helpers](INPUT_RECIPES.md).
