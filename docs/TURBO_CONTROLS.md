# Shortcuts

**R3** toggles the menu in every build. **Hold L3 without L** for turbo teabag
with slight forward creep; release to stop. It alternates crouch/walk once per
observed native update and suspends while busy, airborne or stopped. The
`r3_turbo` / `l3_turbo` config aliases still enable this feature; R3 is menu-only.

Press **X** on the ground for a short-hop tap. Map X to Jump. The shortcut
releases X at native jump squat, preserving horizontal movement without adding
ZL/shield. A fresh airborne X press remains a normal jump.

Press **Y** for the selected [Finisher attempt](FINISHERS.md): Kirby Fair/Dair
or Yoshi Bair. One attempt per press, with a fresh hit required for the finisher.
B-reverse and incoming-hitbox auto-duck remain unbound/disabled. Kirby's optional
[Idle crouch and Dtilt face rows](INPUT_RECIPES.md) are separate from Y.

Hold **L** for ledge autopilot, including Kirby's recovery down tilt. When the
menu is visible its D-pad directions only edit settings; when hidden they return
to slides/ledge trump. [Action ownership](ACTION_OWNERSHIP.md) arbitrates all
proposals, with safety and confirmed follow-ups retaining their priority.

For Training menus and system statistics, see [Training and monitoring](TRAINING_MONITOR.md).
No OS overlay is installed or modified by these source changes. Input recipes
still rely on the selected Smash controller mapping and require Switch testing.
