# Starting-roster guide (legacy)

The old compiled ledge-profile tables on this page have been retired. Current
fighter responses and input schedules are authored in
[`sequences.txt`](SEQUENCE_FILES.md); per-fighter menu details are in the
[fighter guides](FIGHTERS.md).

Statistics and move-frame facts belong only to `data/Ultimate_stats.json`,
described in the
[Fighter Data guide](FIGHTER_DATA.md). Do not use copied timing tables or
external fighter pages as runtime defaults or fallback data.

The configured roster's identities and the dataset's native-kind records are
different catalogs. A fighter profile does not imply a data fallback for a
different native kind, and missing facts remain unavailable.
