# Combo system removed

Custom combo playback, per-fighter combo libraries and combo/mode menu rows have
been removed. Press Y for one of Kirby's two compiled [Finisher attempts](FINISHERS.md).
These do not restore the old generic combo engine. Auto-duck is disabled.
B-reverse is unbound; Kirby
recovery cover runs within held-L autopilot. See [the current ledge menu and
controls](LEDGE_MENU.md). The original portable sequence examples are not wired
to gameplay and perform no runtime work in the plugin.
