# Retired D-pad slide bindings

The hard-coded D-pad Left/Right slide actions are removed. They are not current
controls. D-pad directions now use the fighter's saved input sequence or **Normal
button** from Button configs. The old B-reverse and D-pad Down trump bindings are
also removed.

In Training, use Button configs and R3 to create/edit a sequence. For a repeated
sequence choose its While held loop setting; every movement/air-dodge input still
obeys native game rules. This does not recreate an automatic safe-slide policy.

See [current controls](CONTROLS.md), [button recipes](SEQUENCE_FILES.md) and
[ledge trump](LEDGE_TRUMP.md) for the current ON/OFF mode.
