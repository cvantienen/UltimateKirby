Stream diagnostics

How to read this dashboard
  • Freshness uses this computer’s monotonic receive clock. A record is stale at 250 ms and expires at 1 second. Frozen views do not stop these clocks.
  • sample_us is a sender publication timestamp in microseconds. It is not a game frame, wall-clock date or end-to-end latency measurement. Clocks are not synchronized.
  • sequence orders publications across all objects and groups in a session, not just the selected object. Jumps here are expected when other groups publish.
  • Sequence gaps count unseen sequence positions. Sender queue drops are a separate reported counter; neither is a measured network-loss rate.
  • Motion frames are animation observations, not elapsed receiver time. Rates and history here measure publications, not game FPS.
  • Coverage is bounded: up to 16 fighters, 32 observed attacking weapons/items, and attack slots 0–7. Not every engine variable is available.
Groups & wire types

Object state contains common status, motion, position and capability observations. Attack groups describe individual attack slots, not commands to modify hitboxes. Input distinguishes physical pre-mapping values from mapped results after the existing finishing overlay.

Float: IEEE-754 f32 in the low 32 bits. Signed: two’s-complement i64. Unsigned: u64. Boolean: zero is false, nonzero true. Hex: an identifier or bitmask, not a decimal quantity. Raw bits are always the exact 64-bit word; null has no raw value. Unknown IDs are not guessed or resolved to names.
